# Changelog

## 0.4.0

- Open standard single-resolution `.cool` and multi-resolution `.mcool` files in the read-only VS Code editor.
- Read contact maps with the bundled HDF5 WebAssembly runtime.
- Zoom and pan the heatmap with the toolbar, mouse, or trackpad.
- Browse assembly, contact counts, chromosome lengths, and Cooler attributes in metadata tables.
- Inspect individual bin pairs and export the heatmap as PNG.
